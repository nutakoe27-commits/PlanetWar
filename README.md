# PlanetWar

Сезонная MMO-4X стратегия в реальном времени. Собственный движок на C++20,
пять платформ, серверная авторитетная симуляция, ноль pay-to-win.

> **Статус: Фаза 0.** Готово ядро `pw_core` и ассетный пайплайн на Blender.
> Следующее — платформенный слой и Vulkan (см. [дорожную карту](docs/05-ROADMAP.md)).

## Что это

Космическая 4X-стратегия в духе Stellaris, но соседние империи — живые люди,
а исход партии определяют билды, доктрины, логистика и дипломатия, а не донат
и не количество часов, проведённых онлайн.

Галактика практически безгранична: содержимое систем вычисляется из сида, а не
хранится, поэтому нагрузка на сервер масштабируется от числа онлайн-игроков, а не
от размера вселенной.

## Сборка

```
cmake --preset linux-x64-release
cmake --build --preset linux-x64-release
ctest --preset linux-x64-release
```

Пресеты есть на все шесть целей, включая Android и iOS: `cmake --list-presets`.

Ядро и сервер собираются **без графических зависимостей** — ни SDL, ни Vulkan
для них не нужны.

### Ассеты

```
pip install bpy
python3 tools/blender/build_assets.py --quality preview
```

Blender подключается как модуль, отдельный бинарь и GPU не нужны. На выходе —
спрайтовые атласы в `assets/build/`. Подробности в
[07-ASSET-PIPELINE.md](docs/07-ASSET-PIPELINE.md).

## Ключевые принятые решения

1. **Сезоны 8–12 недель** вместо вечной вселенной — лечит снежный ком, даёт честный замер скилла.
2. **2.5D рендер** — карта в плоскости, спрайты с инстансингом. Летает на телефонах.
3. **Тонкий слой зависимостей** — движок свой, готовое берём только там, где писать своё бессмысленно.
4. **Экономика на слотах и специализации** — глубина из логистики и цепочек, а не из микроменеджмента планеты.
5. **Детерминированная fixed-point симуляция** — общий код клиента и сервера, реплеи, валидация как античит.
6. **Модели в Blender, пре-рендер в спрайты** — картинка 3D-качества при стоимости отрисовки 2D. Вектора в графике игры нет.
